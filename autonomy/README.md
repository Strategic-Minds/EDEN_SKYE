# Eden Skye Autonomous Launch Package

This folder is the Eden Skye source-of-truth install package for the governed autonomous growth system synced with Auto Builder.

## Purpose

Give Eden Skye and Auto Builder one shared operating contract for starting today:

- Eden Skye owns brand identity, campaign psychology, content voice, public persona, offer framing, and approval-safe creative strategy.
- Auto Builder owns orchestration, queue movement, runtime provider checks, cron triggers, Supabase receipts, and draft-only automation flow.
- Connected systems execute only inside approval gates.

- `eden-auto-builder-sync-manifest.json` - machine-readable capability and connector map.
- `start-today-runbook.md` - exact first-day launch sequence.
- `social-growth-method.md` - aggressive platform-safe growth method for Facebook, Instagram, and TikTok.

## Runtime Principle

This package supports maximum safe autonomy.

Allowed by default:

- read connected context
- prepare content drafts
- build content queues
- score posts
- create implementation packets
- log evidence and blockers
- recommend next moves

Requires human approval before execution:

- public social publishing
- Shopify mutations
- Supabase migrations or production data writes
- Vercel production deploys
- payment, discount, or billing changes
- external outbound messages
- paid ad launches

## First Operating Goal

Launch the Eden Skye + Epoxy Will Change Your Life + AI Can't Do This growth system using governed automation:

1. collect intelligence from approved source systems
2. generate draft content and campaign packets
3. route drafts into Xyla, Metricool, and Auto Builder queues
4. publish only after approval
5. measure winners
6. clone winners into new drafts
