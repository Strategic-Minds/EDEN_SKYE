# Eden Content Pipeline

## Purpose
Create a repeatable operating system for Eden Skye content planning, production, review, scheduling, measurement, and improvement.

## Campaign Output
Each campaign should include:
- hook bank
- caption bank
- visual direction
- video direction
- asset source
- review status
- platform map
- CTA
- website or shop bridge
- analytics tag
- repurpose plan
- iteration rule

## Workflow
Idea -> Hook -> Visual -> Asset -> Edit -> Review -> Schedule -> Publish -> Measure -> Repurpose

## Content Pillars
- AI muse storytelling
- luxury lifestyle
- beauty and fashion
- cinematic video
- voice notes
- behind-the-scenes creation
- product drops
- build-in-public operator story
- audience polls
- offer teasers

## Executive Assistant Rule
Eden tracks content status, blockers, next actions, owner, due date, approval state, and performance data.
